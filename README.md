# Phần mềm Thông báo Học phí — Gửi riêng từng Phụ huynh

Web app nội bộ cho GVCN Trường THPT Chi Lăng.

🌐 **Dùng trực tiếp (không cần cài):** https://KimKenPkl.github.io/phieu-thu-hoc-phi/

## Cách dùng mỗi tháng
1. Mở link trên bằng Chrome/Edge, kéo-thả file Excel học phí tháng mới
   (đúng form: STT – HỌ – TÊN – Học phí – Tiền ăn/ở – Xe bus – Tổng tiền).
2. Điền thông tin chung 1 lần: Quyển số, Nợ TK, Ngày thu, Người thu tiền…
3. Bấm tên từng em để xem phiếu thu → sửa nhanh nếu cần.
4. **Tải ZIP ảnh** → gửi từng ảnh cho từng phụ huynh qua Zalo
   (copy tin nhắn mẫu trong app để dán kèm), hoặc **In tất cả** để phát giấy.

🔒 Dữ liệu Excel chỉ xử lý trên trình duyệt của người dùng, không gửi đi đâu.
