# Phần mềm Thông báo Học phí — Gửi riêng từng Phụ huynh

Web app nội bộ cho GVCN Trường THPT Chi Lăng (bản v2.0 — chuẩn năm học 2026–2027).

🌐 **Dùng trực tiếp (không cần cài):** https://KimKenPkl.github.io/phieu-thu-hoc-phi/

## Cách dùng mỗi tháng trong năm học
1. Mở link trên bằng Chrome/Edge, kéo-thả file Excel học phí tháng mới
   (form nhà trường: STT – HỌ – TÊN – Học phí…). **Tháng trong file được tự nhận**;
   nếu file thiếu cột Nội dung, lý do tự tạo theo Năm học / Học kỳ / Tháng đã cài.
2. Kiểm tra danh sách — dòng có ⚠ là Tổng trong file lệch với cộng các khoản, cần đối chiếu.
3. Bấm tên từng em để xem phiếu → sửa nhanh trực tiếp trên phiếu nếu cần
   (Tổng / Còn thiếu / Số tiền bằng chữ tự tính lại).
4. **Tải ZIP ảnh** → gửi từng ảnh cho từng phụ huynh qua Zalo (copy tin nhắn mẫu
   trong app để dán kèm), **Tải Excel theo dõi** để tích “Đã gửi”,
   hoặc **In tất cả** để phát giấy.

🔒 Dữ liệu Excel chỉ xử lý trên trình duyệt của người dùng, không gửi đi đâu.
